              Logos

              Logo library

              The game holds only 20 custom logos. The library keeps all of yours, as many as you like, and you pick which 20 the game gets.

              • Add logos and Import PS3 save put logos in the library. While the game has free slots they also go straight into the game.
              • Click a logo in the library to put it in the game or take it out. Logos in the game have a check mark.
              • Taking a logo out of the game keeps it in the library. The bin on a logo deletes it from the library for good.
              • Logos you make in the game's Paint Tool join the library by themselves.

              Close the game before changing logos.
